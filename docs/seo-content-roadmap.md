## 2. Content Creation Standard Operating Procedure (SOP)

Before any proposed guide is developed and published, it must pass this 5-point quality gate:
1. **Clear Search Intent**: Does the article target a specific query cluster with demonstrated search demand?
2. **Original Technical Contribution**: Does the guide provide working code samples, reproducible architecture diagrams, or concrete rubric checklists not found in generic AI overviews?
3. **Natural Internal-Link Anchor**: Does it link contextually to at least 1 parent Hub and 1–2 related domain landing pages?
4. **No Artificial Keyword Stuffing**: Written for human engineers and students, maintaining a clean reading score and professional tone.
5. **No Cookie-Cutter Templates**: Each guide must have bespoke prose, unique subheadings, and distinct visual assets.
